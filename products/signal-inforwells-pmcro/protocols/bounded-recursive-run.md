# Protocol: Bounded Recursive Run

Receive → Identify → Gather → Apply → Test → Resolve → Refine → Record.

- Default maximum: 3 refinement cycles per task.
- Every repeat must cite a failed criterion or new evidence.
- Do not repeat without changed input, method, or hypothesis.
- Preserve unresolved issues as unresolved.
- If a required source is unavailable, report the gap.
- Failed tests mean the artifact is not validated.
- Maker cannot be the sole checker of its own work.
- Publishing, pushing, posting, deleting, and other consequential external actions require explicit authorization.
- Stop when criteria pass, the cycle cap is reached, evidence is insufficient, or authority is missing.

Formal Recognition records current knowing after examination and cross-checking. Whether Recognition also integrates continuously during examination remains experimental.
