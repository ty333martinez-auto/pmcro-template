# Signal InfoWells × PMCR-O

**Experimental marketplace product · v0.1.0 · not validated for effectiveness**

Signal InfoWells is a reasoning framework for examining reality without allowing any single perspective to define it alone. PMCR-O supplies the product execution discipline: plan, make, check, reflect, and preserve an auditable trail.

## Core boundary
- Awareness
- Six pillars: Perception, Imagination, Empathy, Introspection, Emotion, Reason
- Cross-checking: no single pillar defines reality by itself
- Recognition: after examination and cross-checking, formalize current knowing as **Know / Believe / Suspect / Don't Know Yet**
- Living cycle: Action → Experience → Reflection → Awareness

Whether Recognition also integrates continuously during examination remains an open experimental question. Test 6 (Recognition Gap) is unresolved. A paired baseline comparison is proposed as Test 7, not reported as completed.

## Marketplace layers
1. Signals identify a need: evidence gap, assumption, contradiction, uncertainty, ambiguity, limitation.
2. Skills perform bounded reusable work.
3. Protocols sequence skills.
4. PMCR-O plans, executes, checks, and reflects on the product task.
5. Artifacts preserve findings, evidence, prompts, and run records.
6. Judgment governs process and escalation; it never overrides evidence.

## Included skills
- **Baseline Comparison Harness:** sealed baseline comparison; descriptive results only.
- **Provenance-Aware Run Registry:** traceable run records; uncertainty preserved.
- **Bounded Recursive Run:** Receive → Identify → Gather → Apply → Test → Resolve → Refine → Record.

Default maximum: three refinement cycles. Each cycle needs a failed criterion or new evidence. Maker cannot be sole checker. Consequential external actions require explicit authorization.
