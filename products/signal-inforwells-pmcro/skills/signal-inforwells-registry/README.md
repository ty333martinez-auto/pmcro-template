# Skill: Provenance-Aware Run Registry

Preserve reusable, auditable run records without treating accumulated intelligence as truth.

Required fields: run ID, scenario ID, condition, status, recognition state, evidence, limitations, and provenance (source, method, role, artifact references).

Records are append-only by convention. Corrections should be new linked records, not silent overwrites. Report sample sizes with summaries. A single constructed case must never be promoted into a general claim.
