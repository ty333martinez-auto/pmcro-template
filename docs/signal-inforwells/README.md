# Signal InfoWells website

Responsive static landing page for the experimental Signal InfoWells PMCR-O marketplace product.

## Local preview
Open index.html in a browser. No build step is required.

## GitHub Pages
The workflow at .github/workflows/pages-signal-inforwells.yml deploys this directory when changes land on master. Pages must be enabled and configured to use GitHub Actions. Verify the Actions run and deployment URL; a successful commit alone does not prove the site is live.
